# ADR-112 decor art list

Every piece below already renders through `sprite_fallbacks.json` (fallback chain to the nearest real piece art, tinted/scaled). Art replaces a fallback by shipping a building sprite whose `building.piece` is the key (base) or `<key>@<variant>` (per-variant art).

## Tinting approach
- Paintable pieces (rugs, cabinets, vases, pottery, curtains, tapestries, fence_picket, clan_flag): author the base **greyscale/desaturated** so `BuildPiece.paint` (palette index, Build panel Tint row) multiplies cleanly; `clanTint` pieces use the clan palette.
- Rugs: one tintable base per size (`rug_1x1, rug_2x1, rug_2x2, rug_3x2, rug_round, rug_runner`) plus one pattern overlay per variant (`<size>@striped` ...; untinted white + alpha). Colour x pattern = 8 patterns x palette colours with no per-colour sprites.
- Material sets (`_rustic/_fine/_luxury`) may share one sprite with tier tints until dedicated art exists.
- rotSteps 4 for furniture/fences; wall mounts need N and W facing art (rot&2 = the other face, mirrored).
