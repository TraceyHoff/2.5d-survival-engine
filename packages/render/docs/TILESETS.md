# @engine/render — content integration spec (technical)

This is how the renderer consumes content. It is **not** an art-direction document. Look decisions live in
Art & Assets' `STYLE_GUIDE.md` and `render_tuning.json`.

## 1. Source of truth: the `@engine/assets` registry
- The renderer reads only an `AssetRegistry` from `@engine/assets` (`loadManifest` / `fetchManifest`). It defines no manifest format of its own.
- ECS data holds numeric sprite ids (`Sprite.spriteId u16`, `BuildPiece.visualId u16`). Ids come from `registry.ids.sprites` and are kept stable by `ids.lock.json`.
- `renderer.atlas.setRegistry(registry, sources)` uploads every atlas into one `TEXTURE_2D_ARRAY` (layer size 2048, or 4096 with `atlasLayerSize`). Atlases are shelf-packed whole with a 2 px gap.
  - It also uploads a parallel emissive array and an `RGBA32F` frame table (uv rect, size, layer, has-emissive per frame).
  - All sprites draw with one shader and few draw calls.
- `sourcesFromManifest(registry, manifestUrl, rects?)` maps atlas keys to image URLs. `<image>_emissive.png` is used when the atlas has `emissive: true`.
- Images load through core `AssetManager` (loader kind `render:image`) and are ref-counted. Switching a theme or swapping an atlas releases the images that are no longer used.

## 2. Grid atlases (manifest v1)
- Layout is `frameW x frameH x columns x rows`, frames row-major. Pivot is `sprite.anchor`, normalized from the top-left of the frame (feet = `(0.5, ~0.92)`).
- Directional animations: `directions` is 1, 4, or 8. Row `d` starts at `frames[i] + d * dirStride`.
- Facing: the direction index is `AssetRegistry.directionIndex(facing, dirs)`, where `facing = 0` means the +x tile axis (screen down-right).
  - 8-dir order is `E(+x, down-right), SE(down), S(down-left), SW(left), W(up-left), NW(up), N(up-right), NE(right)`. In names, "E" means the world +x axis, not screen-right.
  - Mirrored rows are baked into the atlas. The renderer never flips characters.
- AnimState → animation name, first match wins (`STATE_ANIMS`):

  | state | names tried |
  |---|---|
  | idle | `idle` |
  | walk | `walk` |
  | run | `run`, then `walk` |
  | attack | `attack` |
  | hit | `hit`, then `hurt`, then `idle` |
  | death | `death`, then `idle` |
  | shamble | `shamble`, then `walk` |

  Time comes from `(tick - 1 + alpha - startTick) / tickHz`. `loop: false` holds the last frame.

## 3. TexturePacker JSON-hash import
`importTexturePacker(json, {key?, category, defaultFps?, oneShot?, emissive?, buildings?})` returns `{atlas, sprites, rects, issues}`.
- Frame names:
  - `<sprite>` or `<sprite>/<index>`: static
  - `<sprite>/<anim>/<index>`: 1 direction
  - `<sprite>/<anim>/<DIR>/<index>`: `DIR` from `E SE S SW W NW N NE` (or a 4-dir subset)
  - The `.png`/`.webp` suffix is ignored.
- Pivot comes from `pivot` (normalized) and trim offsets are respected. fps comes from per-frame `duration` (ms), otherwise `defaultFps`.
- Rotated frames are rejected (turn off "Allow rotation"). Problems are reported in `issues`; nothing throws.
- The result is a virtual grid atlas (`columns = frame count`, 1 row) plus a per-frame rect table. `mergeTexturePacker(baseManifest, imports)` produces a normal manifest and `rects` by atlas key.
  - Pass both to `loadManifest` and `sourcesFromManifest(..., rects)`.
  - TP content goes through the same registry, lock, and validation as everything else.
- Fixture: `assets/debug/zombies_tp.json`, generated by `scripts/make-tp-fixture.mjs` from the sample atlas.

## 4. Building pieces
- Sprite `building: {piece, footprint {w,h}, layer, frames[rotation][damageStage]}`.
- Renderer component `BuildPiece`:

  | field | type / values |
  |---|---|
  | visualId | u16 |
  | variant | u8 |
  | tint | u32 RGBA |
  | damageStage | u8, 0..3 |
  | rotation | u8, 0..3 |
  | level | u8 |
  | layer | u8: 0 floor, 1 wall, 2 furniture, 3 roof |
  | ghost | u8: 0 normal, 1 valid, 2 invalid |

- Transform x/y is the footprint's min tile. Rotations 1 and 3 swap w and h.
- Pivot convention: `IsoRenderer({pieceAnchor})`. The default `"center"` is the footprint centre on the ground, which matches the art guide and the sample (`anchor (0.5, 0.75)` in 128x128 frames). `"front"` uses the front-most footprint corner.
- Depth key = the front-most footprint tile + `z * zFactor` + `layer * 0.01`.
  - Walls split into per-column slices (one per tile column `x - y`), each keyed by its own front tile, so characters sort correctly against long walls.
  - Floors (layer 0, or sprites whose `building.layer` is 0) use ground-plane depth.
- Level height: `style.levelHeightPx` (default 48 px = 3 z steps of 16 px). A piece on level `L` is drawn `L * levelHeightPx` higher.
- Damage: frames from `frames[rot][stage]` when present. Otherwise a procedural crack overlay is used.
- Ghosts are drawn translucent with a green (1) or red (2) pulse.
- Roof / upper-level cutaway: if the focus entity stands under a roof or upper level (`BuildingGrid`, flood fill over covered tiles), layer-3 pieces and pieces above the focus level that touch that region fade to `style.cutawayAlpha`.
- Caching: static pieces go into per-chunk instance buffers (one draw per visible chunk). A buffer is rebuilt only when that chunk's checksum changes. Streamed or newly arrived chunks fade in (`chunkFadeIn`).

## 5. Optional pages and blocks
| file / field | effect |
|---|---|
| `<atlas>_emissive.png` (same layout) | max(rgb)·a is written to the emissive MRT. Those pixels ignore darkness and feed bloom. |
| `sprite.sway {amp px, freq Hz, stiffness}` | vertex wind sway. Weight = (height above pivot / pivot height)^stiffness, driven by Weather wind (or `style.wind` default) plus a per-instance phase. Read with `swayFromManifest(rawJson)` and passed to `atlas.setSway`. |
| Sprite with `LightSource` | marked as a bloom source (emissive G channel) |
| survival_fx `build/*.json` (`{parts:[{atlas, sprites}]}`) | merged into the manifest by the demo (base keys win) |
| `survival_fx/textures/heat_shimmer_rg_128.png` | tileable RG offset noise for heat shimmer (`renderer.setShimmerNoise`) |
| `<atlas>_sheen.png`, `<atlas>_sway.png`, `<atlas>_tintmask.png` | **not yet consumed**; procedural fallbacks are used |

## 6. Look layer (`render_tuning.json`)
- `renderer.loadLook(url)` fetches the file, validates it against `StyleConfig`, and merges it over the neutral defaults.
  - Unknown keys and type mismatches are dropped and returned as warnings. Keys starting with `$` or `_` are ignored.
  - `gradingLut.url` / `gradingLut.keyframes` resolve relative to the tuning file.
- Grading LUT strips: `N` slices of `NxN`, R = x within a slice, G = y, B = slice. `N` is auto-detected (`N = height`, `width = N²`), so 16³ (256x16) and 32³ (1024x32) both work.
- Keyframes: `[{hour, sun, ambient, fog, shadowTint, lut?}]`, colours as `[r,g,b]` or `#rrggbb`.
  - Colours are blended by hour on the CPU. The two keyframe LUTs are blended on the GPU.
  - Ambient = ambient + sun. The fog colour and the shadow tint replace the defaults.
- Bloom samples only emissive-masked pixels and light-source sprites. It never uses a global brightness threshold.

## 7. Gameplay-facing components (injected with `renderer.bindGameplay`)
| component | fields | use |
|---|---|---|
| BuildPiece | see §4 | pieces |
| AnimState | state u8, startTick u32 | animation |
| Wetness | level u8 (Art's 0-3 → 0..255) | darken, sheen, drips (`fx_drip`) |
| BodyTemp | cold u8, heat u8, shivering u8 | shivering gates the shiver; cold scales it and adds a frost rim; heat adds flush and sweat (`fx_sweat_drop`); breath comes from `fx_breath_puff` |
| Emitter (core) | kind u8, radius f32, strength f32, falloff | kind → `renderer.emitterKinds` table (default 1 heat, 2 light). Light kinds add lights; heat kinds drive shimmer. |
| Fuel/Burning | lit u8 | an Emitter on an entity with this component shows only while `lit != 0` |

- Surface wetness and snow cover come from Weather over time until gameplay's per-chunk value is wired in with `renderer.setSurfaceProvider(key => ({wet, snow}))`.
- Weather kinds map through `setWeatherTable`. Unknown kinds fall back to clear.
