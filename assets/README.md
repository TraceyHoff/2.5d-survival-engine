# Cozy-Wild Starter Pack (wave 1)

This is the canonical shared asset folder. Art direction is in [STYLE_GUIDE.md](STYLE_GUIDE.md). Engine wiring is in [INTEGRATION.md](INTEGRATION.md).
Everything here is generated by `python3 tools/build_all.py && python3 tools/audio.py && python3 tools/build_all.py && python3 tools/preview.py && python3 tools/make_readme.py`
(python3, Pillow 12, numpy 2, ffmpeg with libvorbis). The output is deterministic.

Quick look: `preview.png` (= `preview/preview.png`, 2x: `preview/preview_2x.png`), `preview/scene.gif`, `preview/player_walk.gif`, `preview/water.gif`, and `preview/contact_<atlas>.png`.

## Conventions (summary)
- 2:1 iso, tile 64×32, `zStep` 16 px. All PNGs are RGBA8 with straight (non-premultiplied) alpha.
- Atlases are **uniform grids**, the engine manifest v1 format (`frameW/frameH/columns/rows`). The frame index runs row-major. Direction rows are offset by `dirStride` = `columns`.
- **Pivot/anchor** is normalized `(x, y)` within the frame. Characters use the feet, props use the base center, tiles use the diamond center, buildings use the footprint center on the ground, and icons/FX use the frame center.
- 8-direction row order is `round(facing/45°)` with `facing 0 = +x`. On screen that is: 0 down-right, 1 down, 2 down-left, 3 left, 4 up-left, 5 up, 6 up-right, 7 right.
  4-direction order: 0 down-right, 1 down-left, 2 up-left, 3 up-right.
- Each `atlases/<key>.json` next to the PNG is TexturePacker-hash compatible, with frame names and pivots. Individual frames are in `sprites/<category>/<key>/`.
- Characters and zombies have **no baked shadow** (renderer shadow, or `fx_shadow_blob`). Static props carry a soft 30% plum contact shadow.
- Trees, bushes and grass have **no sway frames**. Their sprite entries carry `sway: {amp (px), freq (Hz), stiffness (0..1)}` for the renderer's vertex-shader wind.
